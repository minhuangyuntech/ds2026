Data Structures in C

資料結構 Data Structure

以 C 語言為核心，建立資料結構課程中反覆使用的觀念：抽象資料型態、陣列與鏈結表示、堆疊與佇列、樹、圖、排序、雜湊與進階搜尋結構。學習時可同時追蹤資料如何儲存、操作如何改變狀態，以及成本如何隨資料規模成長。

Roadmap

課程地圖

每個單元都以「資料如何被表示」、「操作成本如何估算」、「程式碼會遇到什麼邊界條件」三個角度安排。
